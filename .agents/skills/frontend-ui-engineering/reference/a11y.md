# Reference — Accessibility (WCAG 2.1 AA)

Antd v5 components are mostly accessible by default. Gotchas:

## Keyboard navigation

```tsx
// Bad: div with onClick is not focusable
<div onClick={handleAction}>Clique</div>

// Good: Antd Button (focusable + keyboard handlers)
<Button onClick={handleAction}>Clique</Button>

// If a custom element is unavoidable:
<div role="button" tabIndex={0} onClick={handleAction}
     onKeyDown={e => e.key === 'Enter' && handleAction()}>Custom</div>
```

## ARIA labels

```tsx
// Icon-only buttons need aria-label
<Button icon={<DeleteOutlined />} aria-label="Excluir solicitação" />

// Inputs get labels via Form.Item
<Form.Item name="email" label="Email"><Input type="email" /></Form.Item>
```

## Responsive

Desktop-first (primary users) but must work on mobile tablets for field use. Use the Antd
Grid; test at 375 / 768 / 1024 / 1920px.

```tsx
import { Row, Col } from 'antd';
<Row gutter={[16, 16]}>
  <Col xs={24} md={12} lg={8}>...</Col>
</Row>
```

`v2/frontend/src/hooks/useResponsive.ts` exposes breakpoint state for conditional rendering.
