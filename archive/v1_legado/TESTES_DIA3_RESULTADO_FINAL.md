## 🔧 CORREÇÕES TÉCNICAS IMPLEMENTADAS

### 1. Schema Harmonization - `MarcadorPlanilha`

**Problema:** Modelo Python divergente da estrutura PostgreSQL real.

#### Campos Corrigidos:
| Campo | Antes | Depois | Motivo |
|-------|-------|--------|--------|
| `id` | `UUIDField` | `BigAutoField` | Tabela usa `bigint` auto-increment |
| `linha` | `IntegerField` | `CharField(20)` | Tabela usa `varchar(20)` |
| `origem` | `max_length=255` | `max_length=32` | Tabela usa `varchar(32)` |
| `origem_aba` | `max_length=100` | `max_length=50` | Tabela usa `varchar(50)` |

#### Campos Adicionados:
- ✅ `tipo_entidade: CharField(50, not null)`
- ✅ `entidade_id: UUIDField(null=True, blank=True)`
- ✅ `raw_data: JSONField(default=dict)`

#### Campos Comentados (não existem na tabela):
- ⚠️ `solicitacao: ForeignKey("Solicitacao")` - HOTFIX DIA 3
- ⚠️ `disponibilidade: ForeignKey("DisponibilidadeFormadores")` - HOTFIX DIA 3
- ⚠️ `remarcado_para: ForeignKey("self")` - HOTFIX DIA 3

### 2. Tratamento Robusto de Emails Vazios

**Problema:** CSV continha linhas sem email, mas `Usuario.email` é `NOT NULL`.

**Solução:**
```python
if not email:
    if cpf:
        email = f"user_{cpf}@aprender.local"
    else:
        email = f"user_{sha1_of_row({'n': nome_completo or nome})[:8]}@aprender.local"
```

### 3. Parsing Inteligente de Nomes

**Implementado:**
- Suporte para campos `Nome` e `Nome Completo`
- Divisão automática em `first_name` e `last_name`
- Fallback robusto quando só há `Nome`

Arquivo já criado: `sql/views_disponibilidades.sql`

```sql
CREATE OR REPLACE VIEW vw_disp_base AS
SELECT s.id, s.matched_user_id AS user_id, s.tipo,
       s.ts_inicio, s.ts_fim,
       tstzrange(s.ts_inicio, s.ts_fim, '[]') AS intervalo,
       s.origem, s.valido
FROM STAGING_TABLE s
WHERE s.matched_user_id IS NOT NULL AND s.valido IS TRUE;

CREATE OR REPLACE VIEW vw_disp_anual AS
SELECT * FROM vw_disp_base WHERE tipo='ANUAL';

CREATE OR REPLACE VIEW vw_disp_desloc AS
SELECT * FROM vw_disp_base WHERE tipo='DESLOC';

CREATE OR REPLACE VIEW vw_disp_bloq AS
SELECT * FROM vw_disp_base WHERE tipo='BLOQ';
```
