# Question frameworks

Clarifying questions for Phase 1, grouped by what is being designed.

## For features

- "What triggers this action?"
- "Who should have access?"
- "What happens on failure?"
- "How does this interact with X?"

## For architecture

- "What's the expected scale?"
- "Where does state live?"
- "What's the consistency requirement?"
- "How do we test this?"

## For UX

- "What's the happy path?"
- "What feedback does the user get?"
- "What's reversible vs permanent?"
- "How does this fit existing patterns?"
