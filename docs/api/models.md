# Models

Os models Django (campos, constraints, choices) são a fonte de verdade no próprio código, em `apps/core/models/`. A referência de contrato de API (endpoints, shapes, códigos de conflito) vive em **[API_REFERENCE.md](https://github.com/matheusnorjosa/aprender_sistema/blob/main/v2/docs/API_REFERENCE.md)**.

Para a estrutura modular atual dos models, consulte `apps/core/models/__init__.py`.
